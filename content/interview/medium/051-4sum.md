You get a list of whole numbers and one target number. The list has between 4 and 250 values, each value is from -1000000000 to 1000000000, and the target is from -1000000000 to 1000000000. Find every set of four values, taken from four different positions, that add up to the target. Return each set as a sorted list of its four values. Two sets that hold the same four values count once, so the answer never repeats a set. Return all the sets in one list, in ascending order (the order Python uses when it sorts lists). If no set adds up to the target, return an empty list.

Sorting the numbers first makes equal values sit next to each other, which lets you skip repeats. After you fix the first two numbers, the other two can be found with two pointers that walk toward each other.

solution: |
  def four_sum(nums, target):
      nums = sorted(nums)
      n = len(nums)
      result = []
      for i in range(n):
          if i > 0 and nums[i] == nums[i - 1]:
              continue
          for j in range(i + 1, n):
              if j > i + 1 and nums[j] == nums[j - 1]:
                  continue
              lo, hi = j + 1, n - 1
              while lo < hi:
                  total = nums[i] + nums[j] + nums[lo] + nums[hi]
                  if total < target:
                      lo += 1
                  elif total > target:
                      hi -= 1
                  else:
                      result.append([nums[i], nums[j], nums[lo], nums[hi]])
                      lo_value, hi_value = nums[lo], nums[hi]
                      while lo < hi and nums[lo] == lo_value:
                          lo += 1
                      while lo < hi and nums[hi] == hi_value:
                          hi -= 1
      return result
