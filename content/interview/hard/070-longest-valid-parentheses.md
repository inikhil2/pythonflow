You get a string s made only of the characters ( and ). It has between 0 and 30000 characters. A piece of s is a run of neighbouring characters. A piece is well formed when every ( in it can be matched with a later ) in the piece, every ) is matched with an earlier (, and no character is left over.

Return the length of the longest well formed piece of s. If there is none, return 0. Checking every piece one by one is too slow for the largest inputs.
