You are choosing projects to finish to grow your capital. You start with `w` capital, and you may finish at most `k` projects. Project `i` needs at least `capital[i]` capital before you can start it, and finishing it adds `profits[i]` to your capital at once. The lists `profits` and `capital` have the same length, from 1 to 2000 projects. Each value is a whole number from 0 to 10000, and `k` and `w` are from 0 to 2000 and 0 to 10000. Each project can be finished at most once.

Return the largest capital you can have after you finish at most `k` projects. If no project is affordable, return `w`. Picking the most profitable affordable project each time gives the best result, and a heap keeps that choice cheap.

solution: |
  import heapq

  def max_capital(k, w, profits, capital):
      projects = sorted(zip(capital, profits))
      heap = []
      i = 0
      for _ in range(k):
          while i < len(projects) and projects[i][0] <= w:
              heapq.heappush(heap, -projects[i][1])
              i += 1
          if not heap:
              break
          w += -heapq.heappop(heap)
      return w
