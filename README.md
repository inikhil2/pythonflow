# PythonFlow

A web app that teaches Python the way a personal tutor would, following the Harvard CS50P syllabus. Lessons and exercises are paired with an in-browser "Run" feature that executes the learner's code and shows the output.

## Stack

- Nuxt 4 with Nuxt Content (lessons and problems live in `content/`)
- CodeMirror 6 editor

## Run locally

```bash
npm install
npm run dev     # http://localhost:3000
```
